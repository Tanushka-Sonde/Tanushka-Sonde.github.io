## What I did

- **Implemented and benchmarked optimization algorithms** (Full-batch GD, SGD, and Momentum) for linear regression; analyzed convergence behavior and visualized optimization trajectories using contour plots and loss curves.
- **Evaluated the impact of feature scaling on gradient descent**, applying z-score normalization to reduce convergence iterations from ~100k to ~1.4k in large-scale linear regression.
- **Developed a linear autoregressive forecasting model** for the Australia Daily Temperatures dataset using lag features, achieving RMSE ≈ 2.23 and accurately capturing short-term temporal trends.
- **Applied low-rank matrix factorization and logistic regression in PyTorch** for image reconstruction/compression and classification tasks, achieving PSNR ≈ 32 dB, 80% compression, and 83.5% accuracy.
