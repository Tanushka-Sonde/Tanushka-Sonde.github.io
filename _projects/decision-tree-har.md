## What I did

- Implemented a **decision tree algorithm from scratch** in Python supporting discrete/continuous features and outputs, using entropy, Gini index, and MSE as splitting criteria.
- Designed a data collection and evaluation pipeline with cross-validation, runtime complexity experiments, and visualization through PCA and TSFEL-based features.
- Conducted experiments on the UCI-HAR dataset to classify static vs dynamic activities using accelerometer signals, achieving reliable per-class precision, recall, and accuracy.
- Compared performance with **scikit-learn’s DecisionTreeClassifier** and extended the analysis with real-world smartphone accelerometer data collected by the group.

**Tech:** Python, PCA, TSFEL, scikit-learn, UCI-HAR
