## What I did

- Developed a **vision-based Cartesian teleoperation system** for the Addverb Heal robotic arm, enabling remote manipulation using visual inputs and hand gestures.
- Built a perception-to-control pipeline using **Intel RealSense, ArUco marker tracking, and MuJoCo simulation** to mirror human motion and guide robot movement.
- Implemented **constraint-aware inverse kinematics** with Mink and deployed real-time joint velocity control via **ROS**.
- Integrated **MediaPipe hand gesture recognition** for intuitive gripper actuation, achieving smooth, low-latency pick-and-place teleoperation.

**Tech:** Intel RealSense, ArUco, MuJoCo, Mink, ROS, MediaPipe
